# 🛒 AL-Araby Oils E-commerce Website

A modern and fully responsive **E-commerce Frontend Web Application** built to showcase and sell natural oils products. The project focuses on clean UI, smooth user experience, and scalable frontend architecture using modern web technologies.

## ✨ Features

* 🛍️ Product listing & product details pages
* 🛒 Shopping cart functionality
* 💳 Checkout page UI
* 🔐 Authentication pages (Login & Register)
* 🔎 Shop page with categories
* 📱 Fully responsive design (Mobile / Tablet / Desktop)
* 🎨 Clean, modern UI with reusable components
* ⚡ Fast performance using Vite
* 🧭 Client-side routing
* 🔝 Scroll to top on route change

## ⚙️ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/ORVEN-dev/AL-Araby-Oils-E-commerce-Website.git
```

### 2️⃣ Navigate to project folder

```bash
cd AL-Araby-Oils-E-commerce-Website
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Run the development server

```bash
npm run dev
```

The app will run on:

```txt
http://localhost:5173
```

## 🚧 Project Status

Independent ORVEN storefront concept with a sample catalogue, browser-local cart
and saved products, and a checkout preview. The demo does not take payments,
create orders, or collect account details.

Cloudflare Workers Builds deploys the Vite build on pushes to `main`. Follow
the `Workers Builds: al-araby-oils` check on the GitHub commit for the build
status and logs.

The [older GitHub Pages address](https://orven-dev.github.io/AL-Araby-Oils-E-commerce-Website/)
uses `npm run build:github-pages` for its repository base path. Both
deployments use the same hash routes. Browser carts and wishlists are stored
separately on each host.
